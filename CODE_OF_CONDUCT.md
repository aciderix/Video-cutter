# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful, be welcoming, assume good intent. Harassment of any
kind is not tolerated. Report violations privately to the maintainers via
issues marked as private or by email to the project owner.
